# Install Update Server:

Download the repo.

```
git clone https://github.com/lydiaperspective/lyd-kde-update-server.git
cd lyd-kde-update-server
```

Rename `sample.env` to `.env` and edit values to yours.

```
# GitHub authentication
GITHUB_USERNAME=githubUsername
GITHUB_TOKEN=githubToken

# Repositories
FORK_REPO=yourRepo.gitLink
UPSTREAM_REPO=https://invent.kde.org/kde-linux/kde-linux.git

# Build configuration
TARGET_BRANCH=branchName
UPSTREAM_BRANCH=master # This is the KDE Linux master branch

# How often to poll for updates (default once a week)
POLL_INTERVAL=604800

# --------------------------------------------------
# GPG signing configuration
# --------------------------------------------------

# Identity associated with the generated signing key
GPG_KEY_NAME="Custom KDE Linux" # Change this to what you want
GPG_KEY_EMAIL=""

# 0 means the key does not expire
GPG_KEY_EXPIRE=0

# Optional: set this to an existing key fingerprint.
# Leave empty to automatically find or generate a key.
GPG_SIGNING_KEY=""

# Host directory where the public key will be exported.
# Relative paths are resolved from the Compose project directory.
GPG_EXPORT_DIR=./key-export

# Public key filename inside the export directory
GPG_PUBLIC_KEY_FILE=kde-linux-signing-public.asc
```

## Build and Launch Container:

```
sudo podman compose up -d --build
```

The container will run, generate the key and export it to `key-export` folder.

# Import Key generated by build server:

- Copy key from `key-export` folder on server to client.

## Import key to client:

```
set -e

KEY_FILE="$HOME/Downloads/kde-linux-signing-public.asc"
KEYRING="/etc/systemd/import-pubring.pgp"
EXPECTED="9F2ACF5A0FCCFACD62299E3B16E03C457E8B2AF0"

# Verify the public key fingerprint
ACTUAL=$(gpg --with-colons --show-keys "$KEY_FILE" |
    awk -F: '$1 == "fpr" {print $10; exit}')

if [[ "$ACTUAL" != "$EXPECTED" ]]; then
    echo "ERROR: Public key fingerprint mismatch!"
    exit 1
fi

# Create temporary GPG home
TMP_GPG=$(mktemp -d)
chmod 700 "$TMP_GPG"
trap 'rm -rf "$TMP_GPG"' EXIT

# Preserve existing locally installed keys, if present
if sudo test -f "$KEYRING"; then
    sudo cp "$KEYRING" "$TMP_GPG/existing.pgp"
    sudo chown "$USER":"$(id -gn)" "$TMP_GPG/existing.pgp"
    gpg --homedir "$TMP_GPG" --import "$TMP_GPG/existing.pgp"
fi

# Import the new build-server public key
gpg --homedir "$TMP_GPG" --import "$KEY_FILE"

# Export all retained keys into a new keyring
gpg --homedir "$TMP_GPG" --export > "$TMP_GPG/new-keyring.pgp"

# Back up the old local keyring, if one exists
if sudo test -f "$KEYRING"; then
    sudo cp -a "$KEYRING" "$KEYRING.backup"
fi

# Install the updated keyring
sudo install -o root -g root -m 0644 \
    "$TMP_GPG/new-keyring.pgp" "$KEYRING"

echo "Build-server public key installed."
```

## Verifiy the key install:

`gpg --show-keys --with-fingerprint /etc/systemd/import-pubring.pgp`

# Setup Client for Updates:

## Edit System Files

In `/etc/sysupdate.d/`
Edit:

- 50-root-x86-64-caibx.transfer
- 50-root-x86-64-erofs.transfer
- 60-esp.transfer
  Under `[Source]` edit the `Path=` to match your update server ip.

## Disable KDE Linux testing redirector

`sudo systemctl disable --now kde-linux-sysupdated.socket`

## Verify the update server manifest is working

`curl -fsS http://127.0.0.1:8485/nvidia580xx-legacy/sysupdate/v2/SHA256SUMS`

## Verify update signature

`sudo /usr/lib/systemd/systemd-sysupdate list`
Result should look similar to:

```
Good signature from "KDE Linux"
Signature verification succeeded.
Operation completed successfully.
```

# Install an update

`sudo /usr/lib/systemd/systemd-sysupdate update`

## Verify the bootloader entry:

`sudo bootctl list`
Result should look similar to:

```
KDE Linux (202611112033) (default) (not reported/new)
```
